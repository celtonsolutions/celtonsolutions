## 🔄 How we work

No surprises, no scope creep. Every project runs through the same four disciplined stages:

1. **Discover** — learn your goals, constraints, and audience before proposing a solution
2. **Design** — prototype and refine, checking in at every key milestone
3. **Build** — develop the approved design into a tested, production-ready product
4. **Deliver** — launch, monitor, and hand off with documentation and support in place
